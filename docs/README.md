# Документация проекта

Проект анализирует видео с нескольких камер, строит локальные треки людей, объединяет их в глобальные треки и показывает результат через web-интерфейс.

## Быстрый запуск

~~~powershell
.venv\Scripts\python -m uvicorn server:app --host 127.0.0.1 --port 8000
~~~

Откройте http://127.0.0.1:8000. По умолчанию используются data, шаг кадров 20, начало 60 секунд и конец 90 секунд.

Каталог hacathon_template-main является незаполненным шаблоном под акустический протокол, а рабочий код проекта реализует видеоаналитику. Поэтому рабочая документация написана отдельно.
