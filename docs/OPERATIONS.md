# Запуск и эксплуатация

## Установка

Из корня проекта создайте виртуальное окружение и установите зависимости:

~~~powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
~~~

Проверьте наличие исходных файлов в data/, весов yolo11m.pt и файлов калибровки. Для формирования H.264-видео нужен доступный FFmpeg с кодеком libx264.

## Запуск web-интерфейса

~~~powershell
.venv\Scripts\python -m uvicorn server:app --host 127.0.0.1 --port 8000
~~~

Откройте http://127.0.0.1:8000. Логи Uvicorn и приложения появляются в той же консоли.

## Параметры нового анализа

Текущие значения по умолчанию рассчитаны на быстрый тест:

- шаг кадров: 20;
- начало отрезка: 60 секунд;
- конец отрезка: 90 секунд;
- порог уверенности: 0.15;
- устройство: CPU;
- Re-ID включён, если доступна модель.

Для полного анализа укажите интервал от начала до длительности исходных видео и уменьшите шаг кадров при необходимости. Малый шаг увеличивает время и объём результатов.

## Запуск конвейера напрямую

Параметры CLI можно посмотреть так:

~~~powershell
.venv\Scripts\python track_project.py --help
~~~

Прямой запуск полезен для диагностики без web-интерфейса. Результат должен содержать tracks_projection.json и каталог tracked/.

## Импорт готового результата

Для импорта подготовленного анализа нужны unified-файл tracks_projection.json и видео в tracked/. Bbox должны быть уже записаны в видео. Клиент не должен наносить их повторно.

## Диагностика видео

Если браузер не запускает видео, проверьте контейнер и кодек:

~~~powershell
ffprobe -v error -select_streams v:0 -show_entries stream=codec_name,codec_tag_string,pix_fmt -of default=noprint_wrappers=1 runs/1/tracked/example.mp4
~~~

Ожидаемые значения: codec_name=h264, codec_tag_string=avc1, pix_fmt=yuv420p. Сервер должен поддерживать byte ranges; запрос с Range: bytes=0-1023 должен вернуть HTTP 206.

## Очистка результатов

Каждый запуск создаёт следующий номер в runs/N. Старые каталоги можно удалять вручную после остановки анализа, если они больше не нужны. Не удаляйте исходные файлы, калибровки и веса вместе с результатами.
