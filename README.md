# Межкамерный трекинг людей

Офлайн-прототип для пяти видео из папки videos. Он использует YOLO для обнаружения людей, локально связывает детекции, получает признаки внешности OSNet и объединяет сегменты в глобальные ID.

## Файлы

- analyze.py — основной анализ, локальная ассоциация, OSNet Re-ID, экспорт report.json и tracks.csv.
- render.py — видео с рамками и глобальными ID.
- app.py — простой просмотрщик; требует доработки под текущие пути и выбор трека.
- detect_render.py — отдельный эксперимент с YOLO и IoU.
- videos — входные видео; yolo11m.pt — YOLO; last.pt автоматически не используется.
- outputs_fixed и rendered_fixed — старые результаты, их нужно пересчитать.
- ТЗ на хакатон_v2.docx.md — требования задачи.

## Как происходит объединение

Для каждой камеры YOLO оставляет только person. Детекции связываются с предыдущими по расстоянию между центрами и HSV-гистограмме. Для сегмента сохраняются рамки, время и средние признаки.

При запуске с YOLO создаётся настоящий OSNet osnet_x1_0 через torchreid. OSNet выдаёт embedding crop человека; нормализованный средний embedding сегмента используется для межкамерного сравнения. HSV используется только при запуске с --no-reid. Сегменты разных камер объединяются при пересечении времени или разрыве до --gap и сходстве не ниже 0.58. Карты допустимых переходов пока нет.

## Установка

    py -3.12 -m venv .venv
    .venv\\Scripts\\python -m pip install --upgrade pip
    .venv\\Scripts\\python -m pip install -r requirements.txt

При первом запуске torchreid скачает веса OSNet. Проверено: OSNet, YOLO и OpenCV работают на CPU. Для CUDA установите подходящий PyTorch и передайте --device cuda.

## Анализ

    .venv\\Scripts\\python analyze.py --videos videos --output outputs_osnet --model yolo11m.pt --step 5 --conf 0.15 --imgsz 1280 --gap 8 --device cpu

Быстрый smoke-тест:

    .venv\\Scripts\\python analyze.py --videos videos --output outputs_smoke --model yolo11m.pt --step 25 --max-frames 250 --device cpu

HSV baseline запускается с параметром --no-reid. В report.json при OSNet должны быть reid: osnet_x1_0 и reid_device. Поле cameras[].frames содержит реальное число кадров.

## Визуализация

    .venv\\Scripts\\python render.py --videos videos --report outputs_osnet\\report.json --output rendered_osnet --hold 30

Старые outputs_fixed и rendered_fixed получены до текущих изменений.

## Проверка

Сначала запустите smoke-тест. Убедитесь, что report.json создан, reid равен osnet_x1_0, а frames для текущих файлов равны 4503, 4504, 4503, 3601 и 4504. Затем обработайте полный набор и просмотрите tracks.csv и rendered_osnet.

Отдельно проверьте переход одного человека, пересечение людей, временное закрытие, выход из всех камер и похожую одежду. Сравните ID с ручной разметкой. total_tracks нельзя считать точным без этой проверки.

## Ограничения

Алгоритм офлайн, не использует план и не дообучает OSNet. Локальная ассоциация жадная, а межкамерные переходы ограничены общим временным окном. Это рабочая база, требующая калибровки.
